# vCartify - Online Store

A modern e-commerce storefront built with React 19, TypeScript, Vite, and Tailwind CSS.

## 🚀 How to Run

### Method 1: Instant Run (No Node.js or install required)
The standalone production build is already compiled into `dist/index.html`.
- Simply double-click or open `dist/index.html` in any web browser (Chrome, Edge, Firefox, Safari).

---

### Method 2: Development Mode (with Live Hot Reload)
1. **Extract the ZIP file** to a folder.
2. Open terminal in the project directory:
   ```bash
   cd mystore
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Start the development server**:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:5173/](http://localhost:5173/) in your browser.

---

### Method 3: Build for Production
To re-build the standalone single-file production package:
```bash
npm run build
```
The output file will be generated in `dist/index.html`.

---

## ✨ Features Included
- **Interactive Filters**: Click to select, re-click to unselect with live active filter pills.
- **Heart Wishlist Burst**: Animated floating heart emoji spread over product images.
- **Fly-to-Cart Animation**: Adding items to cart swoops the product thumbnail into the header cart button with bounce feedback.
- **Order Confirmation Blast**: Thumbs up and delivery emojis explosion with replay button.
- **Search Suggestions**: Instant product preview and category matches while typing.
- **Smooth Animations**: Page entrance, category nav pulses, and hover micro-interactions.
